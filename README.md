# ArthaSutra 2.0

**ArthaSutra** is a single-file Indian personal finance planner built with HTML, CSS, and JavaScript. It helps users understand their income, expenses, savings capacity, investment allocation, tax regime fit, emergency fund needs, insurance gaps, retirement readiness, and financial goals.

> Educational finance planning tool for Indian users. No backend required.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- Google Fonts
- Browser `localStorage`

## How to Run

No installation is required.

1. Download or clone the repository.
2. Open `index.html` in any modern browser.
3. Fill in your profile, finances, and goals.
4. Click **Generate My Plan**.

Because the app uses CDN links for Chart.js and Google Fonts, an internet connection is recommended for the best experience.

## Usage

The app works in four steps:

1. **Profile** - Enter name, age, occupation, city tier, and risk appetite.
2. **Finances** - Enter income, expenses, loans, and other monthly spending.
3. **Goals** - Select financial goals and optional advanced inputs.
4. **My Plan** - Generate a personalized financial blueprint.

The generated plan includes budget health, investment allocation, tax insights, goal timelines, smart calculators, and action steps.

## Data Privacy

ArthaSutra does not send user data to a server. Saved profile data is stored locally in the browser using `localStorage`.

To clear saved data, use the **Reset Saved Data** button inside the app.
